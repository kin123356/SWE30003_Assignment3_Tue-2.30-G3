This document summarizes the key modifications made to the existing files in the Storefront application.

### Core Application (`app.py`)

- **Route Modifications**: The application's main routes were updated to support new features.
  - The home route (`/`) now initializes a shopping cart in the user's session.
  - The `/cart` route was updated to display the contents of the shopping cart.
  - The `/userDashboard` route was modified to fetch and display a history of the user's past orders.
  - The `/adminDashboard` route was enhanced to display sales analytics and was refactored to use a new, centralized inventory system for updating product stock.
- **Error Fix**: Corrected a `TypeError` that occurred because `Product` objects could not be stored in the Flask session. The fix involved changing the shopping cart to store product data as dictionaries (which are JSON serializable) instead of direct objects.

### Data Models (`models/`)

- **`product.py`**: A `from_dict` class method was added to the `Product` class to allow for easy reconstruction of `Product` objects from dictionary data.
- **`productCatalogue.py`**: 
  - The `load_products` method was updated to return `Product` objects instead of raw dictionaries.
  - A `get_product` method was added to retrieve a single product by its name.
- **`catalogueManager.py`**: The `update_stock` method was removed to centralize stock management into a new, dedicated `Inventory` class.
- **`accountManager.py`**:
  - A `get_user_by_username` method was added to retrieve a user's full details.
  - A placeholder `recover_account` method was added to simulate an account recovery process.

### Templates (`templates/`)

- **`index.html`**: 
  - Linked the main stylesheet (`style.css`) to apply styling.
  - An "Add to Cart" button was added to each product listing.
- **`cart.html`**: The placeholder page was updated to dynamically display items in the shopping cart, show the total price, and include a checkout button.
- **`userDashboard.html`**: The placeholder page was updated to display a table of the user's past orders.
- **`adminDashboard.html`**: The page was updated to display a new sales analytics section, including total sales and top-selling products.
- **`login.html`**: A "Forgot Password?" link was added to the login form to direct users to the new account recovery page.

### Static Files (`static/`)

- **`style.css`**: New CSS rules were added to style the product catalog on the home page, displaying items in a grid format.
